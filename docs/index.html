📦 Installation & Quick Start
Integrate the Google SecOps theme into any web application or dashboard.

1. Install via NPM

npm install @secops/theme

2. Import CSS Tokens & Styles

<!-- Include Fonts -->
<link href="https://fonts.googleapis.com/css2?family=Google+Sans:wght@400;500;600;700&family=Google+Sans+Mono:wght@400;500;600&display=swap" rel="stylesheet">

<!-- Include SecOps Theme Bundle -->
<link rel="stylesheet" href="dist/tokens.css">
<link rel="stylesheet" href="dist/secops-theme.css">

3. Set Theme Attribute

<html lang="en" data-theme="dark" class="smp-theme-dark"> ... </html>
<!-- or -->
<html lang="en" data-theme="light" class="smp-theme-light"> ... </html>
